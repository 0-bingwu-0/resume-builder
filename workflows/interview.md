# Interview Me

Ask me the questions in [experience.md](../context/experience.md) one at a time in Chat, so I don't have to fill in the file myself. It works whenever there are open questions: right after setup, for the "Still missing" gaps after a draft, or when I want to add something new.

## Which questions

* **After setup:** the unanswered questions in my question list, ⭐ first, then the rest, section by section.
* **After a draft:** the "Still missing" section of my experience notes, ⭐ first.
* **Something new**, like "Interview me about my new internship": add a block for it in the right section of [experience.md](../context/experience.md), with three to five questions written the way [setup.md](setup.md#how-to-write-the-question-list) describes, then ask them.

## How to ask

* One question per message, in a sentence or two. Name the experience it's about, like "On Kirana Ledger:", so I know where we are.
* If my answer is vague, follow up once with something specific, like what I did myself or a number. If I still don't know, move on.
* "Skip" moves to the next question. "Stop" or "that's enough" ends the interview.
* If an answer brings up something new, like a project the list missed, ask about it before moving on, and add a block for it.

## Saving answers

Save each answer to [experience.md](../context/experience.md) as soon as I give it, so nothing's lost if I stop partway. Write it under its question as short bullets in my words. Keep every fact I give, and nothing I didn't. Once a "Still missing" item is answered, move the answer into that experience's notes and remove the item.

## When it ends

When the questions run out or I stop, tell me in a sentence how many are answered and what's still open. If my resume hasn't been written yet, offer to write it. If it has, update it and export again, following [resume.md](resume.md#edits).
